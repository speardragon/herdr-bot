# herdr bot 1차 범위

사용자가 여러 봇을 만들고 방에 초대하면, 봇들이 각자의 페르소나와 맥락으로 의견을 공유하며 요청에 답한다. 정보 탐색과 산출물 작업 모두 가능하다. 현재의 순차 대화와 발언 제한은 유지한다.

## 남기는 기능

- 봇 생성: 이름, 페르소나, 에이전트 종류, 작업 폴더, 에이전트 실행 권한. 기존 herdr 에이전트 채택 지원.
- 방 생성 및 멤버 관리: 최대 6명. 봇별 DM 및 방의 대화 기록.
- 메시지 작성, 파일 첨부, 방 멤버 멘션, 봇 상태 확인.
- 봇 이름/페르소나 변경, 대화 선택, 이름 변경 및 삭제.
- 한국어 기본, English 선택. 라이트/다크 전환과 선택 저장.

## 제거하는 진입점

Plugin, 계정/로그인/결제 메뉴, 검색/네트워크 등 사이드바 헤더의 부가 동작, 채널/공유/터미널 등 채팅 헤더의 부가 동작, 미구현 음성 입력. 봇·방 이름은 설정/멤버 관리를 위한 클릭 대상으로 유지한다. 설정은 사이드바 하단에 둔다.

## 도구 연결

앱은 Jira/Slack/GitHub/Gmail 등의 연결을 관리하지 않는다. 에이전트가 자신의 기존 CLI/MCP 환경을 이용한다. 앱의 언어 선택은 UI 언어이며, 봇의 응답 언어나 에이전트의 도구 권한을 강제하지 않는다.

## 검증

임시 데이터 및 fake herdr로 봇 생성, 방 생성, 초대, 멘션 선택/전송, 두 봇 응답을 확인한다. 실제 외부 AI와 서비스는 호출하지 않는다. 한국어/English 및 라이트/다크 전환, 재로드 후 유지, 멘션 목록의 뷰포트 경계를 확인한다. npm run check 및 desktop build로 회귀를 검사한다.
